# Исходная область реализации

Язык и эталон описываются файлами этого исходного пакета. Обязательства совместимости ограничены явно заданными форматами и протоколами.

Эталон написан на Python 3.11+ и запускается из `ref/`. TypeScript-приложения пилота требуют Node.js 22+ и TypeScript 5.9.3. Требования к JSON Schema закреплены в `tools/requirements.txt`.

Исследовательские модели служат отдельными конечными оракулами. Их результаты не означают реализации всего языка или приёмки внешних систем.

Правила испытаний — [docs/verification.md](../docs/verification.md).
