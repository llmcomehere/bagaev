# W02. Максимум или значение по умолчанию

Напишите `max_or`: наибольший элемент последовательности; для пустой — значение `d`.

## bagaev

Файл: `main.bag`.

```bagaev
module main
pub fn max_or(xs: Seq<Int64>, d: Int64) -> Int64
```

## TypeScript

Файл: `main.ts`.

```ts
export function maxOr(xs: readonly number[], d: number): number
```
