# bagaev

bagaev — экспериментальный язык программирования для совместной работы человека и LLM. Типизированные связи между правилами, кодом, данными и тестами позволяют вычислять последствия изменения программы.

В репозитории находятся спецификация V1, эталонный интерпретатор на Python, conformance-корпус, исследовательские модели и инструменты опыта A/B/C. Промышленного компилятора на Rust пока нет. Сравнительный опыт с LLM не завершён; подготовка инструментов не доказывает преимущество языка.

## Начало работы

Нужен Python 3.11 или новее. Интерпретатор использует стандартную библиотеку.

```bash
PYTHONPATH=ref python3 -m bagaev_ref --help
python3 conformance/run.py --impl ref --json
python3 tools/check.py
```

Для проверок JSON Schema предусмотрен `bash tools/setup.sh`. TypeScript-пилот требует Node.js 22 или новее и TypeScript 5.9.3: `cd pilot/writability && npm ci`. Эти команды установки загружают зависимости; базовый интерпретатор от них не зависит.
