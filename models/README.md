# Конечные модели R07

В `r07-core` находятся семь моделей: CORE, DATA, AUTH-TX, OBS, LAW, CALL и LINKS. Их код, входы и ожидаемые результаты используются самостоятельными проверками и мостами conformance. Номер R07 обозначает поколение модели, а не Git-тег этого пакета.

Проверка: `python3 tools/check.py --models`. Модели запускаются во временной копии. Ожидания conformance сохраняют ссылки на точные файлы моделей и не подменяются результатами эталонного интерпретатора.

Экспериментальные пакеты R16–R23 не входят в этот исходный пакет. Их архитектурные контракты остаются в `spec/` с указанными границами применимости. Наличие контрактов не подтверждает реализацию или проверку этих расширений.
