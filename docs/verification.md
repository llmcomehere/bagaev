# Проверка исходного пакета

```bash
python3 tools/check.py
python3 tools/check.py --exec
python3 tools/check.py --models
python3 tools/exec_report.py --print
```

Первая команда проверяет ссылки, JSON, технические реестры, грамматику и форму conformance. `--exec` запускает эталон, корпус, мосты к независимым моделям, мутационные проверки, оракулы и пробный харнесс без внешних вызовов. `--models` проверяет семь моделей R07 во временной копии. Экспериментальные пакеты R16–R23 в этот состав не входят.

`PASS` относится к перечисленным проверкам. `SKIP` означает отсутствие требуемой реализации, зависимости или параметров опыта; он не считается успешным исполнением. Промышленного компилятора пока нет. Живой опыт A/B/C не выполнен.

Происхождение ожиданий (`independent`, `model:…`, `derived`) определено в [EXEC_METHOD.md](../registry/EXEC_METHOD.md). Показатель покрытия отражает нормативные правила, а не число файлов или тестов.

JSON Schema использует версии из `tools/requirements.txt`; TypeScript — из `pilot/writability/package-lock.json`. Логи и результаты новых запусков следует сохранять вне отслеживаемого исходного состава.
