# Работа с bagaev

Перед изменением прочитайте [README.md](README.md), [PROCESS.md](PROCESS.md) и спецификацию затрагиваемой области.

- Меняйте реализацию вместе с соответствующим правилом и независимым случаем conformance.
- Сохраняйте идентификаторы правил, связи и ожидаемую семантику.
- Не выдавайте неполную проверку за полную; отсутствие реализации или зависимости показывайте отдельно.
- Храните журналы запусков, локальные настройки, ключи и рабочие материалы вне отслеживаемых файлов.
- Платные вызовы моделей и публикация выполняются только по отдельной явной команде.
- Документация — на русском; идентификаторы API и контрактов сохраняют исходное написание.

Команды проверки: `python3 tools/check.py`, `python3 tools/check.py --exec`, `python3 tools/check.py --models`. Подробности — [docs/verification.md](docs/verification.md).
