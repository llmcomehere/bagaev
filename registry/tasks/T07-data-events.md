# T07 Специфицировать данные миграции и локальные события

Цель: **G03**. Волна: **W3**. Профиль: **V1**.

**Статус и основания готовности** ведутся в [оценках](../../docs/verification.md) и [прогрессе](../../docs/verification.md), исполнимость — в [EXEC-1](../exec-progress.json); наличие этой карточки не означает выполнение.

## Результат

Определить переход кода и сохраняемого состояния без потери авторства и с явной семантикой повторов.

Контекст: [основа языка](../../spec/foundation.md), [цели](../GOALS.md), [дорожная карта](../PLAN.md).

## Входы и зависимости

Предшественники: [T02](T02-program-model.md); [T05](T05-effects-contracts.md); [T06](T06-runtime.md)

- Модель StateVersion T02
- Runtime T06
- Старые и новые схемы авторства

Рабочий материал: [02-language-runtime.md](../../spec/architecture/02-language-runtime.md). Его нужно завершить и проверить, а не считать готовой нормативной спецификацией.

## Решения, которые необходимо закрыть

- Транзакционная граница и требования к адаптеру хранения
- Порядок и доставка локальных событий, dedup и обработка повторов
- Миграция, проекции, восстановление и совместимость схем

## Порядок работы

1. Определить представление состояния, ключей, ограничений и чтения по версии.
2. Задать локальную транзакцию изменения данных и outbox, если профиль использует события.
3. Определить inbox/receipt и область идемпотентности обработки; внешние эффекты вынести из ложного exactly-once обещания.
4. Специфицировать миграцию old single author→ordered authors, проверку инвариантов и перестроение индекса.
5. Рассмотреть сбои до/после фиксации и потери ответа, включая отсутствие обратимой миграции.

## Критерии приёмки

| ID | Проверяемое условие |
| --- | --- |
| T07-C01 | Старая статья сохраняет прежнего автора. |
| T07-C02 | Повтор события не создаёт повторного доменного изменения в заявленной локальной границе. |
| T07-C03 | Производный индекс обновляется или явно остаётся незавершённым. |
| T07-C04 | Принятый Snapshot не объявляется автоматически активированным StateVersion. |
| T07-C05 | Для каждого crash point определено восстановление без догадки о результате. |

## Обязательные отрицательные случаи

- Код обновлён, но индекс хранит только первого автора.
- Откат кода читается как автоматический откат данных.

## Основание завершения

Для каждого критерия сохранить точные версии предметов, входы, метод, ожидаемый и фактический результат. Лог выполненной проверки отличается от проекта проверки. Ревью должно проверить согласованность с зависимыми спецификациями; нулевое число замечаний без просмотра не является свидетельством.

Задача получает `done`, когда её выходы существуют, все обязательные критерии подтверждены допустимыми evidence и результаты приняты по действующим правилам проекта. Подготовка текста даёт `review`, а не автоматически `done`. Для изменения внешних систем нужны соответствующие полномочия; карточка не предоставляет их.

## Если условие не выполнено

Ограничить первый переход остановленным приложением и подготовленной копией данных либо определить реальное журналирование; живую миграцию не подразумевать.

## Исследовательский вход R05

[AUTH-TX-0.1](../../spec/data/authorship-transition.md) и [frozen API](../../models/r07-core/experiments/authorship-transition/API.md) описывают ReplaceAuthorship, event/index/inbox, отдельный ACK и recovery с exact receipts. Фактический отчёт (`r07:results/authorship-transition/report.json`): 594/594 whole-state comparisons, 0 mismatches, 3 выполненных дефекта обнаружены. Начальная D1 уже подготовлена; миграция, activation, общий retention/poison protocol и real storage не проверены, T07 целиком не закрыт.

## Исследовательский вход R07

[Данные](../../spec/language/data-values.md), [value codec](../../spec/data/value-codec.md) и [чистая композиция авторства](../../spec/data/authorship-values.md) уточняют immutable representation и детерминированную запись. Encoder резервирует headroom для последующего decoder и Ok-wrapper. Эта область не заменяет AUTH-TX: physical persistence, migration/activation, event adapter и crash recovery остаются обязательными.
